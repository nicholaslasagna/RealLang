# Task: loop_sum (RealLang)

Write a complete **RealLang** program in a single file that:

1. Uses `module main;` and `fn main() -> i32`.
2. Sums integers `0` through `49999` using `var`, `set`, `while condition(...)`, and `i32` arithmetic.
3. Prints the final sum with `print_i32`.
4. Returns `0` from `main`.

**Do not** use features outside RealLang v0.1 (no arrays, structs, `i64`, `f64`, imports, or macros).

**Expected stdout line:** `1249975000`

Output only the RealLang source file contents.
