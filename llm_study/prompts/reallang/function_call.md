# Task: function_call (RealLang)

Write a complete **RealLang** program that:

1. Defines `fn inc(x: i32) -> i32 { return x + 1; }`.
2. In `main`, loops `i` from `0` to `49999`, accumulating `total += inc(i)` using `var`/`set`.
3. Prints `total` with `print_i32` and returns `0`.

**Expected stdout line:** `1250025000`

Output only the RealLang source file contents.
